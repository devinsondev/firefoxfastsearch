# Firefox Fast Search

Поиск выделенного текста одной горячей клавишей — без контекстного меню.

**F1:** поиск Google в новой активной вкладке (с автоматическим переключением).

**Custom:** отдельная настраиваемая горячая клавиша открывает поиск в фоновой вкладке.

## Использование

1. Открой Firefox 135+ → `about:debugging#/runtime/this-firefox`.
2. Выбери «Загрузить временное дополнение» → `extension/manifest.json`.
3. Выдели слово на веб-странице и нажми F1.
4. Щёлкни значок дополнения, чтобы выбрать другую клавишу, фоновую команду и поисковик.

Поддерживаются Google, DuckDuckGo, Яндекс и Bing. Клавиши можно изменять и сбрасывать.
Ограничения: нет выделения в адресной строке, служебных вкладках и встроенном PDF.
Браузер может блокировать системные комбинации. Пустое выделение ничего не открывает.
Данные поиска не собираются и не сохраняются самим расширением; выделенный текст отправляется выбранному поисковику при открытии страницы результатов.

## Качество

Все файлы ≤377 строк. Запуск проверок: `npm run check && npm test`.
Для постоянной установки XPI потребуется подпись Mozilla. Справка: https://extensionworkshop.com/documentation/publish/signing-and-distribution-overview/

В репозитории находится автономная WebExtensions-версия без сторонних зависимостей.
