# Security and authenticity / Безопасность и подлинность

## English

- Install only from the developer's official GitHub repository or, when available, the Mozilla Add-ons listing.
- The official distributed code uses a **fixed packaged icon**. Users cannot upload another toolbar icon through Settings.
- Forks, third-party screenshots, and repackaged ZIP/XPI files may be altered independently of the official project. Do not treat an isolated screenshot as evidence of the original released code.
- Select text carefully: searches deliberately transmit it to your chosen external search provider.
- To report a vulnerability, open an issue **without posting exploit secrets, credentials, or private search queries**: https://github.com/devinsondev/firefoxfastsearch/issues

## Русский

- Устанавливайте расширение из официального репозитория или, после публикации, из Mozilla Add-ons.
- В официальной сборке **иконка фиксирована**. Загрузить произвольную иконку из настроек невозможно.
- Форки, сторонние скриншоты, перепакованные ZIP/XPI могут отличаться от официальной версии. Один скриншот не доказывает происхождение сборки.
- Поиск намеренно отправляет выделенный текст на выбранный сторонний сайт. Не выделяйте секреты.
- Сообщайте об уязвимостях через GitHub Issues, не прикладывая пароли, токены и частные запросы: https://github.com/devinsondev/firefoxfastsearch/issues
